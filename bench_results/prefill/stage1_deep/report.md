## 1. 弹性系数：AFD 与 baseline 的杠杆结构根本不同

拟合 `ln(TTFT) = b0 + b_bt·ln(bt) + b_rps·rps + b_pre·prefix`（各自 175 cell）：

| 系统 | b_bt（bt 弹性） | b_rps（/rps） | b_pre（/prefix） | R² |
|---|---|---|---|---|
| Baseline DP4xTP8 | +0.312 | +0.027 | -2.535 | 0.770 |
| AFD DP3xTP8+EP8 | -0.127 | +0.162 | -1.999 | 0.735 |

- **bt 弹性符号相反**：baseline bt 翻倍 → TTFT ×2^(+0.312)≈**×1.24（变差 24%）**；AFD bt 翻倍 → ×2^(-0.127)≈**×0.92（变好 8%）**。Stage-3 深挖的反直觉现象在回归层面成立且可量化。
- **AFD 对负载的敏感性是 baseline 的 6 倍**（+0.162 vs +0.027 / rps）：AFD 的甜区深但窄，是用负载敏感性换来的——负载每高 1 rps，AFD 的 log-TTFT 涨幅是 baseline 的 ~6×。
- **baseline 从 prefix 命中获益更大**（b_pre -2.535 vs -1.999）：命中率是两系统共同最强杠杆，但 baseline 更依赖它。
- 三因子解释了两系统 TTFT 变异约 3/4（R²=0.77/0.74）。

## 2. 每步有效时间：'bt 越大 AFD 越快'的最干净量化（中位请求 16936 token, prefix=0, rps4）

一个 16936-token 请求按 `steps=⌈16936/bt⌉` 切分；每步有效时间 = TTFT/steps。

| bt | steps | baseline 每步(ms) | AFD 每步(ms) | baseline 单请求 tok/ms | AFD tok/ms |
|---|---|---|---|---|---|
| 8192 | 3 | 218.4 | 198.8 | 25.85 | 28.39 |
| 16384 | 2 | 356.7 | 246.6 | 23.74 | 34.35 |
| 32768 | 1 | 1063.7 | 459.5 | 15.92 | 36.86 |
| 49152 | 1 | 1385.9 | 468.7 | 12.22 | 36.14 |
| 65536 | 1 | 1596.7 | 466.0 | 10.61 | 36.34 |

- **baseline 每步成本超线性增长**：batch 从 8192→32768（×4），每步时间 218.4→1063.7ms = **×4.9**（比线性还糟，内存/调度压力主导）。
- **AFD 每步成本次线性增长**：同样 ×4 batch，每步 198.8→459.5ms = **×2.31**——attention 与 FFN 异步并发，边际 token 近乎免费。
- 单请求端到端吞吐：baseline **26→11 tok/ms 单调下降**；AFD **28→37 tok/ms 上升后平台**。步数减少直接兑换为总延迟下降（AFD bt8192 597ms → bt32768 460ms；baseline 655→1064ms 反向恶化）。

## 4. Prefix 敏感谱：两系统形状相反

rps8 下相邻 prefix 档的 TTFT 降幅（%），按 bt 取范围：

| prefix 档 | baseline 降幅 % | AFD 降幅 % |
|---|---|---|
| 0->0.25 | 11.6-23.9 | 29.0-60.5 |
| 0.25->0.5 | 26.1-37.1 | 23.3-39.9 |
| 0.5->0.75 | 35.9-65.8 | 24.5-30.4 |
| 0.75->0.9 | 43.6-67.3 | 11.0-22.4 |
| 0.9->0.95 | 2.7-27.9 | 1.7-28.4 |
| 0.95->0.99 | 3.6-25.2 | 21.4-47.8 |

- **baseline 中段最强**：0.5→0.75（36-66%）、0.75→0.9（44-67%）；低段（0→0.25）仅 12-24%。
- **AFD 第一档最强**：0→0.25 降 29-61%（bt8192 高达 60.5%）；中段衰减；尾段 0.95→0.99 再加速（bt32768 48%）。
- **含义**：AFD 的冷缓存惩罚高度集中在 prefix=0 那一点（async 固定开销叠加在全量计算上）；baseline 的惩罚铺满整个中段。**给 AFD 配一点点命中（0.25）的边际收益远大于给 baseline**——ops 上'先喂饱 AFD 的缓存命中'是最划算的杠杆。

## 5. 尾延迟签名：AFD 的均值优势带系统性长尾惩罚

P99/Mean 相对尾比（>2 视为尾粗）：

|---|---|---|---|
| Baseline DP4xTP8 | 2.95 | 138/175 | {'4.0': 2.63, '6.0': 3.12, '8.0': 3.18, '10.0': 3.06, '12.0': 2.77} |

- **AFD 几乎每个 cell 尾比都 >2（174/175），baseline 为 138/175**——长尾是 AFD 的系统性签名。
- 甜区例（bt49152 rps4 prefix0）：baseline 1386/3026（2.18）；AFD 469/1574（**3.36**）——AFD 相对尾更长，但**绝对 p99 仍只有 baseline 一半**。
- 反转例（bt16384 prefix0.99 rps8）：AFD **均值赢**（149 vs 152ms）但 **p99 输**（753 vs 622ms）。在均值咬紧的 cell，AFD 会赢均值输 p99。
- rps≥10 时 AFD 尾比反而收窄到 2.8-2.94——饱和态不再放大尾部，与排队波主导（B2 结论）吻合。

## 6. 负载退化因子：因子 vs 绝对值要分开看

prefix=0 下 rps12/rps4 的 TTFT 放大倍数：

| bt | baseline × | AFD × |
|---|---|---|
| 8192 | 15.19 | 30.84 |
| 16384 | 8.7 | 25.8 |
| 32768 | 7.02 | 18.85 |
| 49152 | 6.01 | 18.57 |
| 65536 | 6.44 | 19.99 |

- AFD 退化因子整体比 baseline 差 2-5×，即便大 batch 仍 ~19×。**但因子会误导**：AFD 大 batch 起点 466ms，19×≈8.9s；baseline 起点 1597ms，6.4×≈10.2s——绝对量级仍接近甚至更好。
- 结论：**用绝对 TTFT（或 SLO 达成）做决策，不要用退化因子**。因子高≠更差，只说明起点低。

## 8. 高 prefix 死区 / 收敛带

- prefix=0.9-0.95：除 rps4 外 **AFD 基本全输**——残留计算太小，dispatch/combine 固定开销主导。
- prefix=0.99：两系统收敛到 150-350ms，胜负落在噪声内（如 bt16384 rps8: 149 vs 152ms；bt32768: 166 vs 164ms）。
- **修正 Stage-1 报告**：`p90+ AFD 反超'应表述为'收敛带 + 噪声内胜负'，无系统性 AFD 优势。
